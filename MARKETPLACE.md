Checks include HTTP status, required/forbidden text, dotted JSON equality, response SHA-256, final URL, content type, latency, redirect count, and all/any logic.

Price: **0.003 USDC / call**.

Best fit: deployment agents, browser/computer-use agents, workflow orchestrators, code agents, multi-agent supervisors and autonomous fulfillment systems.
